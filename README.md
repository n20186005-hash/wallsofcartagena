# Cartagena Walls visitor guide

Independent Spanish and English guide with a native Open-Meteo forecast endpoint.

Use Node 24.12+ and pnpm 11. Run `pnpm install --frozen-lockfile`, `pnpm check`, and `pnpm build`. Cloudflare Workers serves `dist` through `src/worker.ts`; `/api/weather` is handled before assets.

Public facts are attributed on the guide. Photo sources, licences and display crops are linked beside each image. No third-party reviews are published as this guide’s own rating.
